# テンプレート 3A {#template-3a}

[&#x200B; ダウンロードテンプレート 3A](https://51837-micrositemarketo.adobeio-static.net/lp-templates/template-3a.html)を右クリックし、**リンクを別名で保存…**&#x200B;を選択します

>[!NOTE]
>
>テンプレート [のダウンロードと読み込み方法に関する完全な手順については、こちらを参照してください](/help/marketo/product-docs/demand-generation/landing-pages/landing-page-templates/guided-landing-page-template-list.md#how-to-import){target="_blank"}。

![](assets/image2015-6-12-9-3a2-3a8.png)

このテンプレートには、次の内容が含まれます。

* ロゴおよび 3 つのボタンを含むヘッダー（オプション）
* プライマリセクション

  * ヒーローテキストとフォームが含まれます。

* 3 つの本文セクション（オプション）
* フッター（オプション）

**下を右クリックし、_リンクを別名で保存…_を選択します。 このテンプレートをダウンロードするには：**
