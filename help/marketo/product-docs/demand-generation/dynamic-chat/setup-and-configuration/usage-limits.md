# 使用制限 {#usage-limits}

使用制限ページにアクセスして、パッケージ情報や使用制限ステータスなどの重要な情報を確認できます。

1. 設定で、「**[!UICONTROL 使用制限]**」をクリックします。

   ![](assets/usage-limits-1.png)

1. 現在のパッケージ、エンゲージ済み対話の月別制限ステータス、およびカレンダー／ライブチャットのシートの全期間制限ステータスを表示します。

   ![](assets/usage-limits-2.png)

>[!NOTE]
>
>月別の制限は、毎月の初日に自動的にリセットされます。
