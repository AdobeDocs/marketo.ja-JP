# ミーティングリスト {#meeting-list}

Web サイトの訪問者が様々なダイアログを使用してスケジュールしたすべての予定が表示されます。 ここには、予約者のメール、どのエージェントとの予約か、予約日時、および予定した会議時間が過ぎたかどうかが表示されます。

![](assets/meeting-list-1.png)

>[!NOTE]
>
>エージェントのカレンダーに会議が予約されると、エージェントは、訪問者の Dynamic Chat エンゲージメントに関する詳細情報を含む予約のメール通知を受け取ります。

## 失敗したアクション通知 {#failed-action-notifications}

ミーティング予約やライブチャットなどのアクションが失敗すると、ユーザにメールで通知されます。

![](assets/meeting-list-2.png)
