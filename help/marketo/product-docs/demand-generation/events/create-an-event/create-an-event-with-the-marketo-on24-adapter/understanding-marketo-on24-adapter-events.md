# Marketo ON24 アダプターイベントについて {#understanding-marketo-on-adapter-events}

ON24 ウェビナーがMarketoに接続されていない場合は、Marketoに既に保存されている参加者データを取り込んでON24に入力する必要があります。 ウェビナーの後、既に ON24 にある出席情報を取得して、Marketo に戻す必要があります。

ON24 アダプターは、すべての情報転送を行います。 Marketo のランディングページでキャプチャされた登録情報を ON24 にプッシュし、出席情報を Marketo のイベントに自動的に取り込みます。

以降の記事では、ON24 でのウェビナーの作成、Marketo でのイベントの作成、それらの関連付けのプロセスについて説明します。
