# Marketo の中心概念 {#core-marketo-concepts}

Marketo の学習には、いくつかの重要な要素があります。 これらを学べば、Marketo をマスターするまでの半分は達成したことになります。
**![スマートキャンペーン &#x200B;](assets/seo-01.png) スマートキャンペーン** [&#x200B; スマートリストで使用されるスマートキャンペーンを使用すると、アクションのほぼすべてのフローを自動化できます。](https://docs.marketo.com/display/DOCS/Smart+Campaigns)     **![スマートリストと静的リスト &#x200B;](assets/office-35.png) スマートリストと静的リスト** [&#x200B; スマートリストと静的リストは、データベース内の一連のユーザーを定義し、特定の行動をリッスンします。](https://docs.marketo.com/display/DOCS/Smart+Lists+and+Static+Lists)     **![プログラム &#x200B;](assets/office-02.png) プログラム** [&#x200B; プログラムこれらはフォルダーに似ています。 ほとんどすべての操作がプログラム内で実行されます。](https://docs.marketo.com/display/DOCS/Programs)     **![マーケティングカレンダー](assets/office-10.png) マーケティングカレンダー** [&#x200B; マーケティングカレンダーは、マーケティングチームがカレンダービュー内でアクティビティを調整するのに役立ちます。](https://docs.marketo.com/display/DOCS/Marketing+Calendar)     **![モバイルアプリ &#x200B;](assets/mobile-apps.png) モバイルアプリ** [&#x200B; モバイルアプリは、外出先でMarketoを利用します。](core-marketo-concepts/mobile-apps.md)     **![その他](assets/party-11.png)その他** [その他ご存知かと思われる項目](https://docs.marketo.com/display/DOCS/Miscellaneous)
