# サーバーで [!DNL Sales Insight Actions] を許可リストに加える方法を教えてください。 {#how-can-i-allowlist-sales-insight-actions-on-my-server}

残念ながら、1 つの静的 IP アドレスを提供する方法はありません。 [!DNL Sales Insight Actions] はクラウドにデプロイされ、200 を超えるサーバーを利用してメールやユーザーリクエストを処理します。 また、非常に広い範囲の IP アドレスを許可しても、セキュリティが向上するわけではありません。
