# 個人レベルでのメール開封トラッキング {#email-open-tracking-at-person-level}

Adobe Marketo Engageが各ユーザーのメール開封数とクリック数を追跡するかどうかを制御します。 個人レベルの電子メールトラッキングオーバーライドを使用すると、インスタンスレベルでデフォルトを適用し、個々のユーザーに対してそのデフォルトを変更できます。 オープントラッキングとクリックトラッキングは個別に制御されます。

この機能は、電子メールのエンゲージメントが追跡される前に、プライバシー要件や組織のポリシーで同意が必要な場合に使用します。

>[!IMPORTANT]
> 
>この機能は、コンプライアンス要件をサポートするコントロールを提供します。どの法律が適用されるか、どのユーザーが同意を提供する必要があるかは決定されません。 法務部門やプライバシー部門と協力して、トラッキングの設定方法や同意の収集と保持の方法を決定します。

## トラッキング決定の仕組み

3つの設定が連携します。

| 設定 | レベル | 機能 |
|---|---|---|
| **個人レベルの電子メールトラッキングの上書き** | インスタンス | 機能のオンとオフを切り替えます。 オフの場合、Marketo Engageはインスタンスのデフォルトフィールドと人物の上書きフィールドを無視し、通常のトラッキング動作を使用します。 |
| **既定の電子メールトラッキングオフ** | インスタンス | 開いたトラッキングとクリック トラッキングのデフォルトを設定します。 無効にすると、トラッキングはデフォルトでオンになります。 有効にすると、トラッキングはデフォルトでオフになります。 |
| **開封トラッキングの既定値を上書き**&#x200B;および&#x200B;**クリック トラッキングの既定値を上書き** | 顧客 | ブール型の人物フィールド。 値`true`は、そのタイプのトラッキングに対して、インスタンスのデフォルトとは逆の値を適用します。 値`false`または空の値は、インスタンスのデフォルトに従います。 |

上書きフィールドは、自分で「オプトイン」または「オプトアウト」することを意味しません。 **`true`は常に「インスタンスのデフォルトとは逆」を意味します。**

### トラッキング決定テーブル

Marketo Engageでは、電子メールの開封数とクリック数に対して、この決定を個別に適用します。

| 機能 | インスタンスのデフォルト | ユーザーの上書きは`false`または空です | ユーザーの上書きは`true`です |
|---|---|---|---|
| オン | デフォルトでトラッキング オン | Tracked | 未追跡 |
| オン | デフォルトでトラッキングオフ | 未追跡 | Tracked |
| オフ | 該当なし | 通常のトラッキング。オーバーライドとデフォルトは無視されます | 通常のトラッキング。オーバーライドとデフォルトは無視されます |

### 例

機能がオンで、インスタンスのデフォルトがトラッキングされているとします。 ユーザーは&#x200B;**開いたトラッキングの既定値**&#x200B;を`true`に設定し、**クリックしたトラッキングの既定値**&#x200B;を上書きします。 Marketo Engageでは、そのユーザーのメール開封率は追跡されませんが、メールのクリック率は引き続き追跡されます。

## トラッキングモデルの選択

機能を有効にしたり、人物フィールドを入力したりする前に、同意とプライバシー要件に一致するモデルを選択します。

| モデル | インスタンスのデフォルト | 次の場合に上書きを`true`に設定します | 一般的な使用 |
|---|---|---|---|
| オプトアウト | デフォルトでトラッキング オン | 追跡に対する個人オブジェクト | たいていの人は追跡しますが、反対する人の追跡は中止します。 |
| オプトイン（同意） | デフォルトでトラッキングオフ | 追跡に同意する人 | 該当するCNILまたはGaranteのガイダンスの対象となる受信者を含め、トラッキングの前に同意を必要とします。 |

>[!CAUTION]
> 
>上書きフィールドを入力する前にモデルを選択し、その後にインスタンスのデフォルトを変更しないでください。 `true`は「デフォルトとは反対」を意味するため、デフォルトを変更すると、既存のすべての上書き値の影響が反転します。 例えば、デフォルトでトラッキングをオンにしてからデフォルトでトラッキングをオフに切り替えると、以前トラッキングに反対していたユーザーがトラッキングされる場合があります。 デフォルトを変更する必要がある場合は、変更が有効になる前に、影響を受けるすべてのユーザーの上書き値を更新します。

## この機能を有効にします

個人レベルのメールトラッキングオーバーライドは、デフォルトでオフになっています。 これを有効にするには、Adobe カスタマーサポートにお問い合わせいただき、次の情報を指定してください。

1. **個人レベルの電子メールトラッキングの上書きを有効にする**。
2. インスタンスのデフォルトを&#x200B;**デフォルトでトラッキング対象**&#x200B;にするか、**デフォルトでトラッキング対象**&#x200B;にするかを指定します。

>[!TIP]
> 
>Adobeで機能を有効にするように依頼する前に、既存のユーザーの上書きフィールドを入力します。 これにより、イネーブルメント後に最初に作成したメールから、意図したトラッキング動作が適用されます。

## 人物の上書き値の設定

上書きフィールドはブール値の人物フィールドです。 ワークフローに合った方法で設定します。

| メソッド | メモ |
|---|---|
| データ値の変更フローステップ | スマートキャンペーンを使用すると、フォームに同意チェックボックスを送信するなど、オーディエンスが基準を満たした場合にフィールドを設定できます。 |
| フォーム | Marketo Engage フォームのチェックボックスまたは非表示フィールドを人物フィールドにマッピングします。 |
| リストの読み込み | フィールドを読み込みファイルの列として含めます。 |
| REST API | API フィールド名`overrideOpenTrackingDefault`と`overrideClickTrackingDefault`を使用します。 |

相手の同意に応じて各フィールドを設定します。 同意言語で開封数とクリック数を別々に扱う場合は、各フィールドを個別に設定します。

## メールの変更点

Marketo Engageがユーザーをトラッキングしないと判断すると、そのユーザーに送信するメールコンテンツが変更されます。

| のトラッキングがオフ | 変更点 | 未だに機能するもの |
|---|---|---|
| 開封 | このメールには、開封率のピクセルは含まれていません。 **電子メールを開く** アクティビティが記録されていません。 | その他のメール機能（有効な場合のクリックトラッキングなど）。 |
| クリック | リンクは、Marketo Engage トラッキングドメインを介してではなく、宛先に直接送信されます。 非表示のトラッキングリンクは追加されません。 **電子メールをクリック**&#x200B;するアクティビティは記録されていません。 | 購読解除リンク、電子メールフッターのオプトアウトリンク、`list-unsubscribe`、および&#x200B;**Web ページとして表示** リンクは引き続き機能します。 これらのリンクを使用すると、**電子メールをクリック** アクティビティが記録されません。 |

## 影響を受けるメール

| メールタイプ | 上書きが適用されますか？ |
|---|---|
| バッチメール：バッチスマートキャンペーンやメールプログラムから送信されたメールなど | はい |
| トリガーメール （トリガースマートキャンペーンから送信されたメールなど） | はい |
| A/B テストまたはチャンピオン/チャレンジャーのバリエーションを含むメール | はい。 トラッキングは、オーディエンスが受け取るバリエーションに関係なく、各オーディエンスに対して個別に決定されます。 |
| Web ページとして表示 | はい。 Web バージョンは、ユーザーの現在の設定に従います。 変更が表示されるまでに最大1時間かかる場合があります。 |
| 運用メール | いいえ。 通常の追跡行動に従います。 |
| メールのサンプル（テスト） | いいえ。 通常の追跡行動に従います。 |
| メールプレビュー | 変更なし。 プレビューは追跡されません。 |
| アラートメール | 変更なし。 アラートは追跡されません。 |
| SMS メッセージ | いいえ。 この機能は、電子メールにのみ適用されます。 |

## Marketo Engageがトラッキングを決定するタイミング

Marketo Engageは、メールを送信用に準備する際に、ユーザーのオーバーライド値を読み取ります。

- **スケジュールされた配信または遅延された配信：**&#x200B;電子メールが現在準備され、後で配信される場合（例：先頭の開始タイムゾーンや受信者のタイムゾーンなど）、準備時の値が適用されます。 準備後に変更を加えても、そのメールは変更されません。
- **既に配信された電子メール：**&#x200B;人物の上書きを変更しても、既に受信した電子メールは変更されません。 以前に送信した電子メール内のリンクをクリックしても、トラッキングが有効になっている状態でリンクを準備している場合は、そのリンクをトラッキングできます。
- **今後の電子メール：**&#x200B;変更後にMarketo Engageが準備した電子メールには、変更内容が適用されます。

ユーザーが同意を取り消した場合、そのユーザーのために準備された次のメールに変更が適用されるように、上書き値をできるだけ早く更新します。

## レポート、スマートリスト、スコアリングへの影響

Marketo Engageがユーザーをトラッキングしない場合、ユーザーに対して&#x200B;**電子メールを開く**&#x200B;または&#x200B;**電子メールをクリック** アクティビティが記録されません。 これにより、

- **スマートキャンペーン：**&#x200B;対応するアクティビティが追跡されていない場合、**開封メール**&#x200B;や&#x200B;**電子メールのクリックリンク**&#x200B;などのフィルターやトリガーが、そのユーザーに一致しないか、実行されません。
- **レポートとダッシュボード：**&#x200B;電子メールの開封率、クリック率、およびリンクのパフォーマンスは、追跡されたユーザーのみを反映します。 より多くの人が追跡されないと、エンゲージメント指標が減少する可能性があります。
- **スコアリングとプログラムの成功：**&#x200B;開封数またはクリック数に基づくルールとプログラムの成功ステップは、アクティビティが追跡されていないユーザーには適用されません。 これらのルールを見直し、採点が行われたり、不公正に前進したりしないようにする。
- **Web アクティビティの関連付け：** クリック トラッキングがオフの場合、メール リンクにはMarketo Engage トラッキング トークンが含まれません。 その人物がMunchkinにまだ知られていない場合、そのメールからのweb サイト訪問は、リンクを介して人物に関連付けられていません。

**送信済み、配信済み、バウンス済み、および登録解除のアクティビティは影響を受けません。**

## 他のトラッキング設定での動作

個人レベルのメールトラッキングの上書きは、個人のトラッキングをオフにすることができます。 別の設定で既に無効にされている場合、トラッキングは有効になりません。 例えば、`mktNoTrack` クラスでマークされたリンクは、ユーザーの設定でクリックのトラッキングが許可されている場合でも、トラッキング解除されたままになります。

## 機能をオフにする

Adobeがインスタンスの機能を無効にすると、変更後に作成されたメールは通常のトラッキング動作に戻ります。 上書き値は個人レコードに残りますが、無視されます。 機能が後で再度有効になっている場合、保存された値が再度適用されます。

## よくある質問

### 個人の開封数を追跡できますが、クリック数は追跡できません。またはその逆にできますか？

はい。 開封率とクリック率は個別に決定されます。 変更するトラッキングタイプの上書きフィールドのみを設定します。

### この機能は、ユーザーにメールを送信するのを停止しますか？

いいえ。 追跡のみを制御します。 オーディエンスにマーケティングメールを送信するのを停止するには、既存の配信停止および同意機能を使用します。

### 追跡されていないユーザーは、引き続き購読解除リンクの作業を確認しますか？

はい。 購読解除リンクと&#x200B;**Web ページとして表示** リンクは、引き続きすべてのユーザーに対して機能します。

### オプトアウトしたユーザーが「メールをクリック」アクティビティを引き続き使用するのはなぜですか？

オーバーライド値が変更される前に準備されたメール内のリンクをクリックした可能性があります。 変更後に作成されたメールには、変更が適用されます。

### メールテンプレートを変更する必要がありますか？

いいえ。 Marketo Engageは、各メールを作成する際にトラッキング決定を適用します。 テンプレートやメールを変更する必要はありません。
